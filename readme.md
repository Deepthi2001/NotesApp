### commands

``` 
To print all notes               node app.js list 
To add a note                    node app.js add --title "mynotesapp" --body "this is notes app" 
To delete note with title        node app.js remove --title "mynotesapp" 
To read note and print           node app.js read --title "mynotesapp"
To delete all notes              node app.js clear
```
